# TUITIONAPP

A responsive frontend prototype for a single coaching institute.

## Included screens
- Owner overview dashboard
- Fees pending with manually sent WhatsApp reminder links
- Attendance with present/absent controls and WhatsApp alert drafts
- Weekly test report with marks, ranks, progress and parent share links
- Parent portal preview with attendance, homework, fee status, demo UPI QR placeholder and receipt messaging

## Run locally
```bash
npm install
npm run dev
```

## Important
This is frontend-only demo mode. It uses sample data in browser state. No database, authentication, real payment processing, real UPI QR, automatic WhatsApp sending, or generated PDF receipt is connected yet. The QR shown in the parent preview is explicitly a non-payment placeholder.
